FAQ

Common questions, answered clearly.

If something is not covered here, the source documentation and repository are the best references.

What is NotYVOS?+

A development-stage x86-64 operating system with a native kernel, desktop environment, persistent storage, hardware drivers and a PS3 runtime foundation.

Is NotYVOS a Linux distribution?+

No. It is a freestanding operating-system project with its own kernel and userland components.

What hardware does it target?+

The primary architecture is x86-64. Implemented driver and subsystem work includes ACPI, AHCI, Intel e1000, HDA, PS/2, USB, RTL8188EU Wi-Fi integration and a Bluetooth framework. Device compatibility still varies by hardware.

Can it run Windows .exe files?+

No. Windows PE and Win32 compatibility are explicitly excluded from the current roadmap.

Does it include PS3 firmware?+

No. User-supplied PS3 firmware is isolated to the PS3 runtime domain and is not redistributed.

What is the current milestone?+

Phase 19, NYFS Maturity, is active. Phases 16–18 covering networking, Wi-Fi and Bluetooth are delivered. Phase 20 Firewall + Network Security and Phase 21 NotYVFirm are queued.

How can I learn the architecture?+

Read the Architecture and Documentation pages, then docs/architecture.md, docs/data flow.md and docs/roadmap.md in the main repository.

Who develops NotYVOS?+

The project is developed by NotY215.
