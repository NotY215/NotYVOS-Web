FAQ

Common questions, answered clearly.

If something is not covered here, the source documentation and repository are the best references.

What is NotYVOS?+

An experimental gaming-focused appliance that boots to a PS3-style XMB using a Linux kernel, Buildroot, BusyBox init, cage and an SDL2 application.

Is NotYVOS a Linux distribution?+

The current rewrite uses the Linux kernel underneath a minimal appliance userland. It is not the earlier freestanding native-kernel implementation.

What hardware does it target?+

The target is x86-64, with QEMU used for current testing and VirtualBox as the planned primary VM target. Actual hardware and peripheral compatibility are not yet validated.

Can it run Windows .exe files?+

No. The current project is an appliance-style XMB interface, not a Windows compatibility layer.

Does it include PS3 firmware?+

No PS3 firmware is included in the current rewrite. The repository says firmware must remain local/private.

What is the current milestone?+

The repository marks Phase 0 tooling as the current sprint. VirtualBox support, bootable disk packaging, media playback, sound, networking and PS3 game loading remain planned.

How can I learn the architecture?+

Read the repository README.md, ROADMAP.md, docs/architecture.md, docs/BUILDING.md and docs/CONTROLS.md.

Who develops NotYVOS?+

The project is developed by NotY215.
