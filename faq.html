FAQ

Questions about PPSX33.

These answers explain the project's current scope. The source README and roadmap are authoritative for changing implementation details.

What is PPSX33?+

An experimental PlayStation 3 full-recompilation project intended to translate decrypted ELF code into native Windows builds and implement required runtime behavior.

Is it a complete emulator or compatible with every game?+

No. Major compiler, runtime, SPU and graphics areas remain partial or blocked. Universal compatibility is not claimed.

What input does it accept?+

The documented workflow accepts decrypted ELF input. PPSX33 does not decrypt retail content or provide keys.

Does a successful build mean a game works?+

No. Build success proves only that the build stage completed. Correct instruction semantics, imports, system services, SPU behavior, graphics and title-level validation are also required.

What does graphics assist prove?+

Assist cmdstreams and diagnostic draws can test the host graphics path. They do not prove that a game's own commands, shaders or scene render correctly.

Which platform is targeted?+

The current project targets native Windows x86-64 builds. See the core developer guide for current toolchain requirements.

Where are limitations listed?+

See the canonical roadmap and engineering notes.

How can I report a bug?+

Open an issue in the PPSX33 repository with build identity, flags, steps and relevant logs. Do not upload copyrighted game files.
