PPSX33 is an experimental PlayStation 3 full-recompilation project aiming to translate decrypted guest code into native Windows builds while rebuilding the runtime services and graphics behavior real titles require.

CURRENT REALITY

Progress is measured by correctness, not just output.

Compilation, translation counts and diagnostic rendering are useful milestones, but none independently proves bootability or gameplay. The source roadmap is the status authority.

PPU translation trust

PPU lifting and generated C++ are in active development. Instruction semantics, branch recovery, condition registers, memory operations and VMX behavior need continued testing.

Track PPU work ↗

Guest runtime and HLE

Guest memory, imports, LV2 services, PRX behavior, threads, filesystem, audio, saves and input have partial coverage and require title-level validation.

Engineering notes ↗

SPU and RSX/GCM

SPU/MFC/DMA ordering and real title-authored graphics commands and shaders remain major challenges. Assist draws are diagnostic probes only.

SCOPE

An experimental recompiler, not a finished emulator.

PPSX33 accepts decrypted ELF input. It does not decrypt retail game files, distribute game content or keys, or claim universal compatibility. Use only software and game data you are legally entitled to use.
