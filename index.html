NOTYVOS PROJECT

A PS3-style XMB appliance, rebuilt from scratch.

NotYVOS is an experimental gaming-focused appliance that boots directly into a PS3-style XMB interface. The current rewrite uses a silent Linux kernel, Buildroot, BusyBox init, a kiosk Wayland session and an SDL2 XMB app. It is not the previous native-kernel desktop build.

WHAT IS INSIDE

More than a kernel

The current project prioritizes a console-like, keyboard/mouse-driven XMB appliance. Media playback, networking and PS3 game execution are not implemented yet.

CURRENT MILESTONE

Phase 0: tooling and VirtualBox

The repository has been rewritten around a Buildroot/Linux appliance and SDL2 XMB. The current sprint focuses on CMake convenience targets and Windows-first VirtualBox scripts. Media playback, sound, networking, bootable disk packaging and PS3 runtime integration remain open.
