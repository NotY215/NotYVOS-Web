ABOUT THE PROJECT

Building a small OS with a big systems surface.

NotYVOS explores what it takes to build an x86-64 operating system from boot to desktop, while also providing a foundation for PlayStation 3 runtime experimentation.

The idea

NotYVOS is a freestanding x86-64 operating system with a native kernel, ELF user processes, scheduler and syscalls, VFS, persistent NYFS storage, a software-rendered desktop, native device support, and a PS3 runtime foundation. Phase 19 is actively maturing NYFS with journaling, filesystem checking, truncation and permission changes. It is a real systems project, not a themed shell over another operating system.

The project also contains a PS3 runtime foundation with PowerPC execution, SPU, DMA, JIT and RSX compatibility components. These areas are developed as separate runtime domains inside the wider system.

Project philosophy

  • Keep architecture understandable and documented.
  • Prefer native components where practical.
  • Make subsystem boundaries explicit.
  • Document limitations instead of hiding incomplete areas.
  • Keep third-party components attributed and separated.

BOUNDARIES

What it does not claim

Not Windows

Windows PE/Win32 compatibility remains excluded from the current roadmap. Phase 20 is Firewall + Network Security, followed by Phase 21 NotYVFirm.

Not PS3 firmware

PS3 firmware is user-supplied and remains isolated from the native firmware direction.

Not finished

NotYVOS remains a development-stage operating system with substantial queued work.
