ABOUT / PROJECT BRIEF

Recompilation is a systems problem.

PPSX33 is an experimental PlayStation 3 full recompiler. It translates supported guest code from decrypted ELF input into native Windows builds and reconstructs the runtime contracts needed for execution. The current implementation is partial and does not establish general game compatibility.

WHY THIS EXISTS

Make every stage inspectable.

A maintainable path where generated code, runtime behavior and test evidence can be examined independently.

01 / TRANSLATE

Decode and lift

Recover control flow and translate supported guest instruction behavior into host-native code.

02 / RECONSTRUCT

Provide the environment

Implement guest memory, imports, OS-facing services, SPU communication and graphics interfaces.

03 / PROVE

Validate behavior

Use focused tests, strict diagnostics, reproducible logs and per-title observations.

SCOPE & PRINCIPLES

What counts as progress?

IN SCOPE

Engineering direction

Decrypted ELF inspection, PPU lifting, generated C++, native Windows build integration, LV2 and PRX/NID HLE, SPU/MFC/DMA, and RSX/GCM. Vulkan 1.2 is the default host graphics path; OpenGL is secondary.

NOT A CLAIM

Compatibility requires evidence

A successful lift, generated executable, diagnostic draw or Wikipedia game result does not prove that a title runs correctly. Retail decryption is out of scope. Direct3D 11 has been removed from the graphics plan.

Evidence rule

Compatibility claims should identify a reproducible test, known build, specific title and observed result.
