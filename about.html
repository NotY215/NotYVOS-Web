ABOUT PPSX33

Full recompilation, with evidence at every step.

PPSX33 is an experimental PlayStation 3 full-recompilation project focused on translating supported guest code into native Windows builds and implementing runtime behavior real titles require.

Source repository ↗Read the Wiki

Project goal

Build a path from decrypted ELF analysis and PPU translation to native execution, system services, SPU behavior and RSX/GCM graphics.

Honest status

Major compiler, runtime, SPU, HLE and graphics areas are partial, planned or blocked. Follow the current source roadmap.

Evidence first

A successful build, translation count or diagnostic triangle is not proof of correct semantics, boot or playability.

SCOPE

What PPSX33 does and does not promise

Included direction

ELF analysis, PPU lifting, generated C++, native build integration, guest runtime services, SPU/MFC/DMA and RSX/GCM implementation.

Not claimed

Universal title compatibility, complete hardware parity, fully correct HLE, complete shader translation or successful gameplay. Retail-content decryption is out of scope.
