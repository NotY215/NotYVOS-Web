ABOUT THE PROJECT

Recompilation, with evidence at every step.

PPSX33 is an experimental PlayStation 3 full-recompilation project. Its goal is to translate supported guest code into native Windows builds and progressively implement the runtime behavior real titles require.

PPSX33 repository ↗Current roadmap
01

Project goal

The work spans ELF analysis, PowerPC PPU lifting, generated native code, runtime services, SPU/MFC/DMA behavior and RSX/GCM graphics. A successful translation stage is only one part of the complete pipeline.

02

Honest status

Subsystems are tracked as implemented, partial, planned or blocked. Lift counts and diagnostic draws are not compatibility scores. Claims about a game booting or being playable require repeatable, title-specific evidence.

03

Input and boundaries

PPSX33 accepts decrypted ELF input. It does not decrypt game files, distribute keys, or launch external emulators. Use only game data and software you are legally entitled to use.

PROJECT STATUS

Implementation is not compatibility.

PPSX33 is not a complete PS3 emulator. Semantic correctness, runtime services, title-authored graphics and playable game paths require separate verification.
