PPSX33

An experimental PlayStation 3 static recompiler for decrypted ELF64 big-endian PowerPC64 input. It includes a C/C++ core, CLI, C# WinForms GUI, project workflow, PPU lifting, early SPU runtime paths and partial RSX FIFO/control processing. PPSX33 is not a complete PS3 emulator.

IMPLEMENTATION STATUS

What is in the codebase

ELF64 analysis

Loads big-endian PowerPC64 ELF segments, handles entry/function descriptors, discovers symbols and OPD entries when available, detects likely PRX/NID strings, and extracts embedded SPU images.

PPU static lifting

Generates host-side C++ in chunks. Integer, branch, memory, floating-point and VMX paths have broad but uneven coverage. Some operations remain approximate or use fallback behavior.

GUI and CLI workflow

Project creation, ELF loading, lifting, build invocation and report viewing are available. The GUI includes settings for graphics backend, PPU thread count and RPCS3 path, plus progress display and cooperative cancellation. Windows output can include game.exe, ps3rt.dll and guest_image.bin.

SPU runtime foundations

SPU context, local-store handling, loading/execution helpers, mailboxes and MFC/DMA paths exist in the runtime. ISA coverage, vector and floating-point semantics, full channel support and SPURS remain partial and require focused validation.

RSX path

FIFO method decoding and a flip/control path are present, with early raster and host presentation work. Complete RSX behavior and production host GPU backends are not established.

Runtime compatibility

Guest memory, PPU state, syscall helpers and selected LV2/PRX stubs are under development. Recent work expands GOW3 startup-related LV2/PRX handling, but external-call resolution and runtime startup remain experimental.

Keyboard mapping

The GUI defines default DualShock-style keyboard bindings: arrow keys for the left stick, H/J/K/U for the right stick, V for Start, Space for Select, Backspace for the PS button, and letter/numpad/modifier keys for face buttons, D-pad and shoulder controls. End-to-end guest input is still unverified.

CURRENT PRIORITIES

Runtime correctness before claims of compatibility

GOW3 is the primary runtime target

The recorded GOW3 analysis reaches 100% reported static lift coverage, but runtime startup remains experimental. The roadmap still tracks an early halt at pc=0x39800000 and incomplete TOC/r2 handling. Recent code and documentation updates expand LV2/PRX startup coverage, but do not establish a successful boot.

San Andreas and GTA V now have documented static-lift and ELF-analysis snapshots. GTA V records 6,934,214 translated instances across 847 chunks, but its exact input provenance and semantic review remain pending. Minecraft, Uncharted 2 and Demon's Souls remain lift-only stress targets.

Validate each layer independently

The synthetic smoke test checks the lift/build pipeline with a generated PPC64 ELF. It does not establish commercial-game compatibility. SPU execution, RSX rendering, library behavior and guest operating-system expectations require separate tests.

Use the repository's lift reports and game records for exact per-run details. Commercial ELF files, EBOOT files, keys and proprietary assets are not included in the project repository.

BUILD ENVIRONMENT

Windows development

Current documented setup uses CMake, Ninja, a C++17-capable compiler, the Windows SDK and .NET 8 for the GUI. Visual Studio 2022 or a compatible newer version with Desktop development with C++ is supported. The Alpha 01 package is intended for Windows x64 and may require the .NET 8 Desktop Runtime.

From a configured developer command prompt, run scripts\\build_all.bat. Build output is placed under build\\dist\\. The GUI target may be skipped when the .NET SDK is unavailable.

For the synthetic pipeline check, use scripts\\run_smoke_test.bat on Windows or bash scripts/run_smoke_test.sh on supported Unix-like environments. Alpha 01 release notes describe the intended package contents and validation checklist; they do not certify that the final archive passed clean-machine testing.
