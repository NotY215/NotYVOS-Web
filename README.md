# PPSX33 Website

Public source for the PPSX33 project website.

- Live website: https://ppsx33.xo.je/
- Main project: https://github.com/NotY215/PPSX33
- Host routing layer: https://github.com/NotY215/Web-host/tree/main/PPSX33

## Website structure
- `index.html`: PPSX33 landing page
- `ppsx3.html`: detailed project and implementation status
- Supporting pages: `about.html`, `architecture.html`, `documentation.html`, `roadmap.html`, `updates.html`, `faq.html`, `developer.html`
- `assets/css/` and `assets/js/`: shared styling and behavior
- `sitemap.xml` and `robots.txt`: search indexing metadata

## Accuracy policy
PPSX33 is an experimental PlayStation 3 static recompiler, not a complete PS3 emulator. Separate implemented, planned, and untested work. Static lifting, translation counts, and diagnostic output do not prove commercial-game compatibility or playable rendering.

## Hosting
The `PPSX33/` directory in [Web-host](https://github.com/NotY215/Web-host/tree/main/PPSX33) routes clean URLs to this repository and serves shared assets from the canonical source.
