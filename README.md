# NotYVOS Web

Official website for NotYVOS, a lightweight x86-64 operating system project by NotY215.

Built with PHP, HTML5, CSS, JavaScript and TypeScript source. The site contains responsive multi-page documentation, architecture, roadmap, FAQ and developer pages.

Main project: https://github.com/NotY215/NotYVOS

The website requires a PHP-capable Apache host. GitHub Pages does not execute PHP.
