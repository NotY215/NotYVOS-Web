# NotYVOS Website

Public source repository for the NotYVOS website.

The live site is rendered by the separate private Web-host repository. This repository contains page content, documentation, styles, client-side scripts, screenshots, and public website metadata.

## Layout

- `pages/` page content
- `assets/` CSS, JavaScript, TypeScript, and public images
- `Updates/` development screenshots
- `docs/` website documentation
- `robots.txt` and `sitemap.xml` public crawler metadata

The host layer fetches these public files from this repository. No PHP is required here.

Live site: http://notyvos.gt.tc/
Main project: https://github.com/NotY215/NotYVOS
