SYSTEM ARCHITECTURE · CURRENT REWRITE

From boot to the XMB.

The current PPSX33 repository is a full-recompilation project. Its goal is to boot into a PS3-style Cross Media Bar interface without exposing a normal login or terminal to the appliance user.

BOOT AND SESSION

The current execution path

Canonical implementation details live in docs/architecture.md and the root README.

Firmware

seatd + cage

PPSX33-xmb

native build pipeline supplies the kernel and root filesystem. The kernel configuration suppresses the normal boot logo and console output. BusyBox starts the session script, which launches seatd and cage in kiosk mode, then starts the native runtime application. The session script is configured to restart the UI if it exits.

The project is designed as an appliance interface, not a general-purpose shell environment. Shell utilities still exist internally because init scripts require them, but no getty/login prompt is intended to be exposed in the normal session.

UI LAYER

native runtime application

The main UI lives in src/xmb/main.cpp; input mapping lives in src/xmb/input.hpp.

Canvas and animation

A logical 1920×1080 canvas is scaled to the screen. The background uses procedural wave geometry and animated section/item movement.

Sections and settings

Users, Settings, Photo, Music, Video, Game, Network, PlayStation Network and Friends. Settings include theme colour, display, system information, restart and shutdown.

Input

Keyboard and mouse navigate the XMB. Keyboard bindings emulate common DualShock-style controls; native controller USB/Bluetooth support remains planned.

DATA AND MEDIA

Current filesystem expectations

Photo, Music and Video list files from /data/Photo, /data/Music and /data/Video. Actual media playback is not implemented yet. Persistent disk/ISO packaging and shared-folder convenience are still on the roadmap, so these paths depend on how the runtime filesystem is prepared.

Fonts are read from the repository's fonts/ directory and optional section icons from assets/icons/. The post-build script stages fonts and assets into the target image.

HOST BUILD AND TEST

native build pipeline first, VM workflow next

Full OS image

./scripts/build.sh builds native build pipeline, kernel and root filesystem. Current documented outputs include build/out/images/bzImage and rootfs.ext4.

QEMU

./scripts/run-qemu.sh boots through the current direct-kernel test path. A finished bootable ISO/VDI package is not yet available as a completed feature.

UI development

./scripts/dev-run.sh runs the XMB on the host desktop for fast iteration, without appliance power actions being enabled.

FUTURE DIRECTION

PS3 runtime is not in this rewrite yet

The roadmap includes possible integration of PPU, SPU, DMA, RSX and a GameRunner. These are future plans only. The current PPSX33 rewrite does not load PS3 games, does not provide a working PS3 emulator, and does not implement media playback, networking or sound yet. The separate PPSX33 project page describes that independent experimental recompiler codebase.

PS3 firmware is kept local/private and is not committed. No Sony code or assets are included in this rewrite.
