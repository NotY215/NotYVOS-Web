ARCHITECTURE / SYSTEM MAP

From guest executable to host execution.

The current source tree is organized under src/core, src/processor, src/RSX, src/games-stuff and src/UI. Vulkan 1.2 is the default host graphics path, OpenGL is secondary, and Direct3D 11 has been removed. Each stage has its own assumptions, failure modes and validation requirements.

02 / SUBSYSTEMS

Boundaries that must agree

CPU

PPU and generated code

Instruction decoding and lifting, branches, CR/LR/CTR/XER, memory, floating point and VMX. Translation counts do not prove semantic correctness.

OS

Runtime and HLE

Guest address space, import/NID dispatch, LV2, PRX, threads, files, audio, input and saves. These services remain partial and need module-level and title-level tests.

SPU

SPU / MFC / DMA

Execution state, DMA tags, completion order, channels and synchronization.

GPU

RSX / GCM

FIFO GET/PUT progress, command decoding, resources, textures, render targets, shader translation and presentation. Assist draws validate only the host graphics path, not title-authored rendering.

HOST

Native platform

Build configuration, graphics backend, windowing, paths and diagnostics.

QA

Validation

Focused tests, strict faults, reproducible logs and per-title outcomes.

03 / DEBUGGING

Trace failures from the earliest boundary. The immediate critical path is PPU recovery around sticky PCs and import islands, honest null-loop/soft-break handling, FIFO GET/PUT correctness, guest PUT progress without boot assist, then title-authored draws and shaders.

1
Validate input and loading

Check ELF sections, imports and guest address mapping.

2
Inspect translation semantics

Compare guest instructions and control-flow recovery against tests.

3
Inspect runtime contracts

Trace imports, memory, thread scheduling and synchronization.

4
Trace SPU and graphics

Confirm guest-produced commands before relying on diagnostic assists.
