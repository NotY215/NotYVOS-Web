SYSTEM ARCHITECTURE

From guest ELF to a native build.

PPSX33 connects static analysis and code generation to a host runtime. Each stage has its own correctness requirements and failure modes.

PPSX33 repository ↗Current roadmap
01

1. Load and analyse

The loader reads supported decrypted ELF input, maps relevant segments and gathers metadata needed for code analysis.

02

2. Lift guest code

The PPU lifter translates supported PowerPC instruction regions into generated native source. Instruction recognition is not the same as correct instruction semantics or control-flow recovery.

03

3. Link runtime services

Generated code depends on guest memory, imports, LV2/HLE, PRX, SPU/MFC/DMA and other system behavior. These services remain incomplete and must be validated against real call paths.

04

4. Render and validate

The developing RSX/GCM path connects guest command processing to host presentation. Diagnostic or assist draws only validate a limited host path, not the game's own scene rendering.

PROJECT STATUS

Implementation is not compatibility.

PPSX33 is not a complete PS3 emulator. Semantic correctness, runtime services, title-authored graphics and playable game paths require separate verification.
