DEVELOPMENT ROADMAP

NotYVOS, phase by phase.

Phases 0–10F and 11–18 are delivered. Phase 19, NYFS Maturity, is active. Recent code adds NYFS journaling, fsck, truncation and chmod support, plus shell commands. Phase 20 Firewall + Network Security and Phase 21 NotYVFirm remain queued. Windows PE/Win32 compatibility and Brave/VLC validation are excluded.
