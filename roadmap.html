ROADMAP / LIVE ENGINEERING STATUS

Track engineering work by dependency and status.

This page follows the current ROADMAP.md in the PPSX33 core repository. Work is grouped by engineering dependencies and current implementation status. The repository roadmap is the canonical source of truth.

CURRENT CRITICAL PATH

Correct execution before compatibility claims.

The immediate goal is to recover guest execution honestly, establish real FIFO progress without boot assistance, and only then validate title-authored graphics.

01
PARTIAL

PPU recovery and import islands

Improve recovery beyond sticky program counters and import islands while respecting banned regions. Preserve reliable control flow and do not invent valid targets when recovery fails.

02
PARTIAL

Null loops and soft-break handling

Make null-loop and soft-break escape behavior explicit and diagnosable. Recovery must not silently turn an invalid guest path into apparent success.

03
PARTIAL

FIFO GET/PUT correctness

Keep GET advancement tied to accepted command work. Track guest and host progress separately so diagnostic activity cannot be mistaken for title execution.

04
BLOCKED ON HLE / BOOT

Guest PUT progress without boot assist

Establish genuine guest command-buffer progress with boot FIFO injection disabled. The current default assist is a probe, not proof that a title is submitting graphics work.

05
BLOCKED ON GUEST PUT PROGRESS

Title-authored draws and shaders

After guest PUT advances correctly, validate real GCM command streams, resource setup and shader behavior. Assist command streams and non-zero method counts prove only parts of the host RSX path.

SUBSYSTEM STATUS

Current implementation, by engineering area.

These labels describe the code and evidence reported by the core roadmap. They are not game compatibility ratings.

PARTIAL

Baseline and diagnostics

Project reports and strict-fault mode exist. Reproducible host builds, soft-recovery logging and CI build plus smoke-test coverage still need work.

PARTIAL / IN PROGRESS

PPU translation trust

Instruction emission is broad but incomplete. Decoder and code generation separation, no-silent-no-op guarantees, architectural regression tests and differential validation remain outstanding.

PARTIAL

Guest runtime and HLE

Guest memory, import/NID dispatch, threads, synchronization, filesystem, saves, audio and input are incomplete. Module-level HLE tests are planned.

PARTIAL

SPU, MFC and DMA

Interpreter and runtime paths exist, but full instruction coverage, transfer ordering, tag completion and SPURS lifecycle behavior need stronger tests.

PARTIAL

RSX and GCM

Vulkan 1.2 presentation and guest RGBA upload paths exist. Title GCM streams remain blocked; shader translation, textures, depth, blending and render targets are incomplete.

PLANNED

Optimization after conformance

IR optimization, shader caching, incremental lifting and native SPU jobs come after correctness gates, not before them.

DESKTOP WORKFLOW

What is already recorded as complete?

The core roadmap reports these GUI workflow items as done. This is workflow status, not a claim of universal game support.

DONE

Build and run handoff

Copy to Game Folder unlocks after a build, and Run Game EXE unlocks after copying completes. Runtime logs are shown in the Report tab.

DONE

Runtime packaging baseline

The intended distribution keeps the required runtime DLL beside the executable, without a duplicate runtime DLL folder.

DONE

Decrypted ELF input

The GUI accepts decrypted ELF input only. Retail decryption and external emulator launching are not part of the workflow.

EVIDENCE RULES

Never confuse a probe with a game result.

IMPLEMENTED

Code or workflow exists

The implementation is present, but edge cases and semantic correctness may still be unverified.

TESTED

A repeatable test passes

A focused test demonstrates a bounded behavior. It does not automatically establish full subsystem or title correctness.

TITLE EVIDENCE

Observed in a game

Record the title, build, exact path, logs and limitations. Static lift counts, a visible window, injected draws or a successful compile do not prove playability.

Diagnostic flags: PS3RT_STRICT_FAULT=1 halts on sticky or unknown guest PCs rather than inventing targets. PS3RT_INJECT_SEED=0 disables boot FIFO assist. The default assist probes a command stream while guest PUT is idle and is not title rendering.
