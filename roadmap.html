PPSX33 full-recompilation roadmap.

PPSX33 is focused on full PlayStation 3 game recompilation into native Windows builds. This roadmap tracks translation, runtime, graphics and validation work. This page follows the new root ROADMAP.md.

CURRENT CRITICAL PATH

Correctness before compatibility claims

The root ROADMAP.md is authoritative; this page is a summary.

  1. PPU control flow: improve sticky-PC and import-island handling.
  2. Fault correctness: prevent recovery from fabricating successful execution.
  3. FIFO correctness: preserve GET/PUT truth and advance guest PUT without boot assist.
  4. Title-authored graphics: unblock real guest command streams.

Assist command streams can produce method and draw counts. That validates parts of the host RSX path only, not game rendering.

VALIDATION RULES

What evidence means

  • PPSX33 is a native Windows x64 recompiler, not a complete PS3 emulator.
  • Input is decrypted ELF; PPSX33 does not decrypt EBOOTs or provide keys.
  • Lift counts and generated builds do not prove correct semantics, successful boot or playable games.
  • PS3RT_STRICT_FAULT=1 supports correctness runs; PS3RT_INJECT_SEED=0 disables boot FIFO assist.
  • Assist draws are probes, not evidence of title-authored graphics.
