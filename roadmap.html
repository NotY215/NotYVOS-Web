ROADMAP / ENGINEERING PRIORITIES

Progress, in dependency order.

This is a summary of the critical path. The core repository roadmap remains the canonical status source.

Canonical roadmap ↗Architecture map
CURRENT FOCUS

Correctness before compatibility claims.

Prioritize semantic recovery and observable guest progress before expanding claims about title support.

01
FOUNDATION

PPU recovery and semantics

Improve control-flow recovery and instruction fidelity across condition registers, branches, memory, floating point and VMX. Keep focused tests aligned with fixes.

02
EXECUTION

Runtime progress without invented success

Track the first failing PC, import resolution, thread lifecycle, waits and guest memory. Unsupported calls must remain diagnosable.

03
SPU / MFC

Transfer and synchronization behavior

Validate DMA tags, completion ordering, channels, atomics and workload progress.

04
RSX / GCM

FIFO and guest-authored work

Establish command-buffer progress and decoding, then resource creation, shaders and title-authored draws.

05
VALIDATION

Repeatable, narrow results

Distinguish compile, launch, menu, rendering, input, audio and sustained gameplay milestones.

STATUS LANGUAGE

Separate code from demonstrated behavior.

IMPLEMENTED

Code exists

Behavior and edge cases may still need testing.

VALIDATED

A test passes

A repeatable test exercises the behavior and records the outcome.

TITLE-PROVEN

Observed in a game

A documented game path demonstrates the feature with known limitations.
