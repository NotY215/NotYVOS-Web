DEVELOPMENT ROADMAP · UPDATED 2026-10-15

PPSX33 full-recompilation roadmap.

PPSX33 is focused on full PlayStation 3 game recompilation into native Windows builds. This roadmap tracks translation, runtime, graphics and validation work. This page follows the new root ROADMAP.md.

CURRENT STATUS

What exists in the rewrite

These are implementation notes from the current README and roadmap, not claims of a finished appliance.

✓

Boot/session foundation

ELF analysis, PPU lifting, runtime integration, RSX/GCM graphics and reproducible validation.

✓

XMB interface

Users, Settings, Photo, Music, Video, Game, Network, PlayStation Network and Friends sections; theme/display/system information and power-menu UI.

!

Known gaps

Media playback, sound, networking, bootable ISO/VDI packaging and PS3 game loading are not implemented yet. Network/PSN/Friends are placeholders.

ROADMAP TRACKS

Phases 0–8+

Phase 0 is the current sprint. Later phases are planned, not completed features.

PHASE 0 · CURRENT

Project Hygiene & Tooling

Windows-first VirtualBox scripts, root CMake convenience targets, updated controls/build documentation and reliable repeated VM launch workflow.

Working
PHASE 1

VirtualBox First-Class Support

Produce/attach a bootable VDI or supported disk image, set VM defaults, and document keyboard, mouse, USB and optional Bluetooth passthrough.

Planned
PHASE 2

Packaging & Boot Experience

Bootable ISO/disk image, persistent media-data partition and a smooth transition from boot into the XMB.

Planned
PHASE 3

Media & Desktop Completeness

Real photo/music/video playback, basic sound, theme refinements and network-section implementation.

Planned
PHASE 4

Input & Controllers

Refine DualShock mapping, add native USB/Bluetooth controller support and hotplug behavior while retaining keyboard/mouse input.

Planned
PHASE 5

PS3 Runtime Foundation

Long-term investigation of PPU/SPU/DMA/RSX runtime integration and GameRunner. No PS3 game loading is implemented in the current rewrite.

Planned
PHASE 6

Performance & Native Lean

Profile-guided performance work, JIT improvements, graphics translation and SPU scheduling after runtime foundations exist.

Planned
PHASE 7

Hardware & Distribution

Test on real x86-64 hardware and prepare release disk images with clear setup and firmware/data boundaries.

Planned
PHASE 8+

Long-Term Extensions

Possible online features, plugins, multi-user profiles, cloud-save experiments and other architectures.

Future
IMPORTANT BOUNDARIES

Separate implemented work from planned work

  • The current repository is the PS3 recompiler codebase, focused on translating guest code and building a native runtime.
  • The UI is an native runtime running in a cage kiosk Wayland session; it is not a general-purpose desktop shell.
  • Photo, Music and Video currently browse files, but playback is not implemented.
  • Network, PlayStation Network and Friends are placeholder sections.
  • PS3 firmware remains local/private, and game loading/runtime integration is future work.
  • QEMU direct-kernel boot is the documented current testing path. A finished bootable disk/ISO/VDI package is still open.
