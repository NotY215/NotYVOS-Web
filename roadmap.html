CURRENT CRITICAL PATH

Dependencies before compatibility claims

External audits are leads until confirmed by tests or title logs.

PPU recovery and semantics

Partial. Improve sticky-PC and import-island recovery; prevent null-loop or soft-break paths from inventing success.

FIFO GET/PUT correctness

Partial. GET should advance only after accepted work, and guest PUT must progress without boot assist.

Title-authored graphics

Blocked. Real title draws and shaders depend on guest command submission and PUT progress without assist.

Runtime coverage

Partial. Expand measured LV2/HLE, PRX, SPU/MFC/DMA, file, audio, input and save behavior with tests.

flowchart TD
  BASE[Trustworthy baseline] --> PPU[PPU recovery and semantics]
  PPU --> RT[Guest runtime and HLE]
  RT --> SPU[SPU / MFC / DMA]
  RT --> RSX[FIFO GET/PUT and RSX]
  SPU --> TEST[Conformance and title evidence]
  RSX --> TEST
  TEST --> OPT[Optimization after correctness gates]
STATUS RULES

Read roadmap labels carefully

Done

The defined task is complete to its stated scope, not necessarily full PS3 compatibility.

Partial / in progress

Implementation exists but remains incomplete, untested or not fully integrated.

Blocked / planned

A dependency prevents progress or work has not started. Diagnostic assist does not clear a blocker.
