About the developer

NotY215 is the project identity used across the developer's open-source work. PPSX33 is an experimental PlayStation 3 recompiler focused on native Windows builds. Runtime services, SPU behavior, RSX/GCM rendering and title compatibility remain under development.

Project work

PPSX33 is one part of a wider collection of software projects. The development approach emphasizes readable source, documented architecture, practical tooling and honest roadmap boundaries.
