DIAGRAMS AND ARCHITECTURE

Keep diagrams editable

Use Mermaid syntax for flowcharts (compatible with Mermaid renderers such as Beautiful-mermaid), PlantUML for sequences, Graphviz DOT for dependency graphs, Markwhen for timelines, and Scrawl sketches for early design exploration. Source text should live beside the documentation. Automatic website rendering requires an explicit renderer integration.

VALIDATION RULES

What counts as evidence?

Compilation is not execution

A generated file or successful native build does not prove correct PPU semantics, HLE compatibility, or game boot.

Diagnostic graphics are not gameplay

Assist cmdstreams and diagnostic draws test limited host paths; they do not establish title-authored scene rendering.

Strict mode for correctness

Use PS3RT_STRICT_FAULT=1 so unknown or sticky guest PCs are not treated as successful recovery.

Reproducible reports

Keep build identity, input provenance, flags, logs, analysis reports and observed outcomes together.
