CURRENT TECHNICAL GUIDE · 2026-10-15

Documentation for the XMB rewrite.

PPSX33 has been rewritten as a lightweight, gaming-focused appliance that boots into a PS3-style XMB. This page describes the current Linux/Buildroot and SDL2 codebase, not the previous native-kernel desktop implementation.

HOW IT RUNS

Boot and session flow

Firmware
→
Linux / Buildroot
→
BusyBox init
→
notyvos-session
→
seatd + cage
→
notyvos-xmb

The kernel is configured to suppress the normal boot logo and console. BusyBox starts the session script, which launches a kiosk Wayland compositor and the SDL2 XMB interface. A shell still exists for init scripts; the intended appliance interface does not expose a terminal or login screen.

BUILD AND TEST

Current development workflow

Build the full image

./scripts/build.sh
./scripts/run-qemu.sh

The Buildroot build downloads and builds its toolchain, kernel and root filesystem, so it requires the documented host packages and roughly 25 GB of free disk space. Current QEMU workflow boots the kernel directly. A finished bootable ISO/VDI workflow is still planned.

Run only the XMB UI

./scripts/dev-run.sh

The desktop development path requires SDL2, SDL2_ttf, SDL2_image and CMake. Optional environment variables NOTYVOS_FONTS, NOTYVOS_ASSETS and NOTYVOS_DATA override the resource/data paths.

VirtualBox

The current roadmap prioritizes Windows helper scripts to create a VM and launch the latest image. The scripts and disk-image workflow are under active development; do not assume a ready-made bootable VDI/ISO is already published.

KNOWN LIMITATIONS

What is not implemented yet

Media

Photo, Music and Video currently browse files under /data/Photo, /data/Music and /data/Video. Actual playback is not implemented.

Connectivity and sound

Networking, Wi-Fi, Bluetooth and sound remain planned work for this rewrite.

PS3 games

Game loading, firmware integration and the PS3 runtime are not implemented in the current rewrite. Network, PlayStation Network and Friends sections are placeholders.
